# 麦麦去留 · mcd-stay-or-go

同一顿麦当劳，到店自取 / 得来速 / 麦乐送三条路。先问你还要多久，再告诉你该不该出门。

麦当劳程序员创意开发大赛参赛作品 · 基于官方 MCP · **非麦当劳官方产品**。默认只做决策，不自动下单。

---

## 怎么用

本机先打开小程序。要让 Agent 按实时菜单核价，再配 Token。

### 打开小程序

```bash
python3 miniapp/server.py
```

浏览器打开 http://127.0.0.1:8765 。汉堡、小食、饮料按小白楼店当前菜单分开点选。套餐不用自己点，能盖住你选的品会自动拿来比。默认是板烧鸡腿堡加薯条，到店选更便宜的三件套。

价格来自仓库里的官方核价快照，页面上写了采集时间。这一秒的实时价仍要走下面的 Token 和 Cursor。

### 让 Agent 实时核价

四步：拿到 Token → 配进 Cursor → 把 `SKILL.md` 交给 Agent → 复制下面的话去问。

### 1. Token

1. 打开 [麦当劳 MCP 开放平台](https://open.mcd.cn/mcp)，点右上角 **登录**，手机号验证。
2. 回到首页，点 **控制台** → **激活**，同意服务协议。
3. 复制 MCP Token。建议放到本机环境变量，不要写进仓库：

```bash
export MCD_MCP_TOKEN=你复制的Token
```

变量名与 `.env.example` 一致。Token 无效或没带上时，工具返回 `401`；同一 Token 每分钟超过 600 次返回 `429`。

### 2. Cursor MCP 配置

Cursor：**设置 → Tools & MCP → Installed MCP Servers → Add Custom MCP**。在打开的 `mcp.json` 里粘贴（全局文件是 `~/.cursor/mcp.json`，只给当前仓库用则是项目里的 `.cursor/mcp.json`）：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer ${env:MCD_MCP_TOKEN}"
      }
    }
  }
}
```

环境变量在 Cursor 里读不到时，把 `${env:MCD_MCP_TOKEN}` 换成控制台复制的 Token。保存后回到设置页，`mcd-mcp` 应显示 **已连接**，并能看到麦当劳工具列表。

同一份接入地址和请求头也写在 `mcp-config.example.json`（官方示例带 `"type": "streamablehttp"`）。**不要把真实 Token 提交进 Git。**

让 Agent 按本项目裁决，而不是直接去点餐：在对话里让它阅读仓库根目录的 `SKILL.md`，或把该文件放到 Cursor 能读到的 Skill 路径。

### 3. 可复制的提问

`Ctrl/Cmd + L` 打开 Agent。信息越全，越不容易先被追问。缺「吃什么 / 在哪 / 多久能到」时，Agent 会先问再核价。

一次给齐，直接出裁决：

```text
想吃巨无霸套餐。人在天津小白楼，走路大概 10 分钟能到店。时薪按 50 算。到店自取、得来速、麦乐送哪条划算？先别下单。
```

只给出门上限：

```text
我还有 15 分钟能出门。得来速和麦乐送哪个值？最多愿意花 15 分钟。想吃板烧鸡腿堡，人在上海徐家汇。
```

只想知道临界时薪：

```text
省这点钱值不值得下楼？我想吃麦辣鸡腿堡套餐，城市上海，位置人民广场，步行大约 8 分钟。时薪先别问我，告诉我临界值就行。
```

确认结论之后才下单（不说这句话不会创建订单）：

```text
按刚才的到店自取创建订单。
```

### 4. 回复长什么样

核价成功后，回复固定是这一段（下面是 `fixtures/sample_quote.json` 的天津小白楼快照，时薪 ¥50；实时价以当次 MCP 为准）：

```text
## 裁决：到店自取

按你给出的时薪约 ¥50/小时，「到店自取」综合成本最低（到手价 + 时间成本）。临界时薪约 ¥132/小时：时薪低于它更值得选「到店自取」，高于它更值得选「麦乐送」。

| 通道 | 门店 | 商品 | 到手价 | 你要花的时间 | 备注 |
|---|---|---|---:|---:|---|
| 到店自取 | 麦当劳天津小白楼地铁站朗香街餐厅 | 巨无霸三件套 | ¥36.50 | 7 分钟 | 步行约 101m |
| 得来速 | 天津真理道得来速餐厅 | 巨无霸三件套 | ¥37.50 | 12 分钟 | 驾车约 3.8km |
| 麦乐送 | 麦当劳天津小白楼地铁站朗香街餐厅 | 巨无霸中套餐 | ¥51.90 | 0 分钟 | 含配送 ¥6 + 打包 ¥1.9 |

临界时薪：约 ¥132/小时
（时薪低于它更值得出门；高于它更值得外送）

价格来自官方核价。确认后可说「创建订单」。
```

没给时薪时，原因句会改成「到店比麦乐送省 ¥15.40，但要多花 7 分钟」。某条通道没核价成功，会标明「该通道未核价成功」，不会把没算过的路说成更便宜。回复末尾会再问一句：要不要换品、带券重算，或改时薪 / 出门上限。

## 它解决什么

「点外送贵一点但不用动」和「下楼能省十几块」天天纠结。差价不只藏在餐品标价里，还藏在配送费、打包费，以及三套互不通用的券池里。外送菜单编码也和到店不一样。

本 Skill 对三条通道分别走官方 `calculate-price`，再用到店 ETA、出门上限、自评时薪做裁决。输出是：**按你现在的时间，去还是留。**

| | 常见省钱助手 | 麦麦去留 |
|---|---|---|
| 第一问 | 预算 / 最省 | 你还要多久能到店 |
| 输出 | 推荐套餐 | 去 / 留 一句话裁决 |
| 默认动作 | 常引导凑单 | 决策辅助，默认不下单 |

## 仓库里还有什么

```text
miniapp/                 # 本机小程序：python3 miniapp/server.py
SKILL.md                 # Agent 主指令（裁决口吻与调用顺序）
MCP_INTEGRATION.md       # 用到的 MCP Tool 与调用链
CONTEST_DECLARATION.md   # 参赛声明
scripts/decide.py        # 临界时薪 / ETA 裁决（不调用 MCP）
scripts/test_decide.py
fixtures/sample_quote.json
mcp-config.example.json
.env.example
```

不连 Token 也能看裁决长什么样：

```bash
python3 scripts/decide.py --fixture fixtures/sample_quote.json --wage 50
python3 -m unittest scripts/test_decide.py -v
```
